A program that writes the entrant's own make.fun username — one word, nothing else — to `/output/entry.txt` for make.fun's "One Word, One Username, One Reward" bounty, $5 in USDC.

The word is `bright-badger-24`: the entrant's genuine make.fun handle, in make.fun's own adjective-animal-number shape. The judge's brief weighs genuineness first — a non-genuine word loses to any genuine handle — so the handle itself is the entry. It also lands on the later criteria: a bright badger is a cheerful image that needs no explaining, the alliterative b-b plus number sticks after one look, it is a single token with no spaces or padding, and it is a friendly handle its owner happily wears.

Verification: `main.ts` run twice → byte-identical `entry.txt` (16 bytes, valid UTF-8, inside the 1–30 gate, not only whitespace, no trailing newline).

## Run it

```sh
node main.ts
```
